# 複数ページ漫画の単調化防止

本Skillは2ページ以上の新作・続編・作り直しで必須。脚本、画風設計、画像生成、PNGレビューの各工程から呼び出す。レビュー重点の低さを理由に省略しない。以下は本キットの制作・検査規則であり、数値だけで漫画の品質を保証するものではない。

作品側の記録先は `docs/production/PAGE-VARIATION.md`。配布元の雛形は `templates/manga-project/docs/production/PAGE-VARIATION.md`。`BRIEF.md`、`TEXT-STORYBOARD.md`、`DIALOGUE.md`、`ART-DIRECTION.md` と対応させ、同じ台本を複数の文書へ重複転記しない。

## 1. 何を統一し、何を変えるか

統一するのはキャラクターの顔立ち・髪・体格・衣装、線質、彩色、世界観、文字の系統、装飾の語彙。**同一人物であることは、毎回同じ表情・ポーズ・画角であることではない。**

場面に応じて設計し直すのは、コマの大小と配置、主役となる絵、人物の立ち位置、視線、眉・まぶた・口、手と身体の動作、カメラ距離、会話の働き、情報の見せ方、間、ページ末の引き。タイトルとノンブルの共通デザインは許可するが、紙面全体の固定とは区別する。

### LAYOUT COPY BAN

- 参照画像は「キャラ同一性」「画風」「レイアウト」の用途を区別する。レイアウトの明示指定がない限り、参照ページのコマ境界・顔の位置・表情・まとめ欄を全ページへ複製しない。
- 「この形式で」は、読み味・画風・教材としての密度を継承する指示か、厳密な固定枠の指定かを文脈で判定する。不明な点は制作上の仮定を記録する。既に十分な指示があれば余分な確認待ちを作らない。
- 前ページ全体を唯一の参照画像にして「同じ構図で次の内容」と指示しない。可能なら人物参照を切り出し、画風の共通指定とページ固有ネームを別々に渡す。
- 装飾を豪華にする、背景の色を変える、左右を入れ替える、見出しと本文を差し替えるだけでは、展開の変化として数えない。

## 2. 生成前の全体設計 — PLAN GATE

最初の完成画像を生成する前に、依頼範囲の全ページを一覧にする。5ページ以上では一覧を省略しない。2〜4ページでは短い表でよい。長期連載は今回制作する範囲と直前の接続ページを対象とする。

各ページに次を記録する。

1. ページ機能：導入、事件、対立、交渉、発見、比較、余韻など。そのページで何が変わるかを動詞で書く。
2. 因果と接続：前の出来事を受けて誰が何をし、その結果が次ページへどうつながるか。
3. コマ設計：コマ数、各コマの位置・大きさ、右上からの読む順、最大コマと視線の出口。
4. 主ビジュアル：そのページにしかない中心の絵。案内役の顔を毎回最大の絵にしない。
5. 視点・距離・配置：誰の視点で、引き・中景・寄りをどう使い、人物をどこに置くか。
6. 感情と演技：主要人物の入り→変化→出口と、それを示す具体的な表情・身体動作。
7. 会話の働き：尋ねる、推測する、反論する、確かめる、選ぶ、黙って受け止める等。語尾だけでなく行為を変える。
8. 情報提示：現場の行動、短い説明枠、地図、相関図、比較図、資料、年表などから必要なものを選ぶ。図解なしも可。
9. まとめ欄：有無と学習上の必要性。毎ページの自動挿入を既定にしない。
10. 前ページとの差分：構図・演技・会話・情報提示などの実質的な違い。意図した反復があれば対象と理由。

隣接ページの違いを少なくとも二つの観点から確認する。ただし、差分の数を稼ぐために連続動作や空間関係を壊さない。差分が小さい場面は、意図した反復として意味と変化する要素を具体的に記録する。

同じコマ数だけでFAILにはしない。逆にコマ数だけ違っても、主ビジュアル・人物配置・会話・結論が同じなら設計し直す。「10ページ中20%まで」「毎ページコマ数を変える」などの一律の割当で判断しない。

PLAN GATEは全ページの役割と前後の接続が確認でき、理由のない反復が解消してからPASS。表を埋めただけではPASSにしない。

## 3. 表情とポーズ — EXPRESSION / ACTING LOCK

主要人物ごとに、場面の刺激→判断→反応を字コンテへ指定する。喜怒哀楽の単語だけでなく、目線を伏せる、口を閉じて考える、一歩下がる、資料へ身を乗り出す、手を止める、相手を見る等の観察できる演技で書く。

- 生徒役を毎回「口を開けて驚く→質問→納得の笑顔」に固定しない。
- 解説役を毎回「同じ笑顔で正面を向いて指さす」に固定しない。
- マスコットを毎ページ同じ位置・同じ表情で結論を復唱させない。登場させないページも選べる。
- 同じ胸上の正面構図を全ページの導入と締めへ自動配置しない。横顔、後ろ姿、手元、全身、無言の反応、場面だけのコマも内容に応じて使う。
- 深刻な事件、失敗、危機の場面で、理由なく全員を笑顔や軽い相づちにしない。

表情を変えるために性格を別人にしたり、顔立ち・年齢・衣装を変えたりしない。人物の一貫性と感情の変化は別々に監査する。

## 4. 展開と教材構成 — BEAT VARIATION LOCK

「質問→解説→納得→ポイント四つ→ここが大事→次回予告」をページ共通テンプレートにしない。同じ会話機能が3ページ以上続いたら必ず再点検し、意味のある変化や明示した意図がなければFAIL。

教材漫画では、次の形式を目的に応じて組み合わせる。順番や使用回数を固定しない。

- 物語中心：事件、選択、行動と反応で内容を進める。
- 図解中心：比較や関係の理解に必要なときだけ大きな図を置く。
- 混合：物語で生じた疑問を図解で解き、その理解が次の行動を変える。

大きな解説パネルを使うページと、場面を読ませるページの緩急をつける。各ページに導入・解説・要点・まとめを全部載せない。総まとめは原則として章末に置き、途中で置く場合はその必要性を記録する。同じ知識をナレーション・セリフ・四分割カード・最後の教訓で重複説明しない。

事件のページは事件、交渉のページは交渉を主役にし、案内役の講義にすべてを置き換えない。ページ機能の名前だけを変えて同じ紙面を使うのもFAIL。

## 5. ページごとの生成指示 — PAGE DIVERSITY LOCK

共通のStyle Lockに加えて、そのページのコマ設計、主ビジュアル、感情と演技、情報提示、前ページとの実質的な違いを必ず渡す。

`PAGE DIVERSITY LOCK: 画風とキャラクター同一性は維持する。このページ固有のネームと演技を優先し、参照ページや前ページのコマ割り・顔の位置・表情・まとめ欄・会話展開を自動複製しない。差分はPAGE-VARIATION.mdの当該ページに従う。`

READ ORDER / COLOR / DIALOGUE / HIGH RESOLUTION の各Lockも維持する。多様性のために右→左の読み順、確定文字、教材の正確さ、実解像度を犠牲にしない。

計画確認のためだけに「全10ページを一枚に描いたコラージュ」を画像生成しない。完成ページは一枚ずつ独立して作る。文字後置きを選ぶ場合も、白い吹き出しの絵を完成ページとして提出しない。

## 6. 生成後の全体検査 — VISUAL GATE

単ページの出来がよくても、そのまま全体を合格にしない。

1. 初めに、設計上異なる2〜3ページができた時点で並べて確認する。単調化が出ていたら、同じ設定で残り全部を生成する前に原因を修正する。不要なユーザー承認待ちや専用の追加画像生成は挟まない。
2. 完成した実画像から縮小一覧を作る。これは確認用の一覧であり、マスター画像を縮小・上書きしない。
3. 隣接ページと離れたページを比較し、同じ段組み、同じ大きな顔、同じ立ち位置、同じ四分割まとめが並んでいないかを見る。
4. 実画像の顔と身体を読める倍率で確認する。驚き顔・指さし・笑顔が台本と無関係に反復していないかを確認する。
5. 全ページを順に通読する。毎回同じ質問と相づちで終わっていないか、前ページの出来事が次を動かしているかを確認する。
6. 表の計画と実画像を照合し、予定した変化が実際に描かれたかを確認する。レイアウト名・感情ラベル・プロンプトが異なるだけでは合格にしない。
7. FAILは該当ページのネーム・演技・会話へ戻して直し、前後ページとの接続を再確認する。文字や背景色だけの差し替えで済ませない。

記録には、対象ファイルと版、比較ページ、実際の観察、PLAN GATE / VISUAL GATEの判定、修正箇所、未確認事項を残す。縮小一覧は文字の正確さの検査を代替しない。画像を見られなかった場合はVISUAL GATEを未確認とし、完了・PASSと報告しない。

### FAILとなる典型例

- 全ページが「上段に同じ案内役の顔／中段に同じ幅の説明コマ／下段に四つのポイント／最下段に教訓」で、内容だけ置き換わっている。
- 同じ人物がすべてのページで同じ表情・同じ身振りをし、場面の変化と対応していない。
- 各ページが説明をリセットして始まり、最後に納得するだけで、因果・発見・行動の積み重ねがない。
- 画風がそろっていることを理由に上記の反復を見逃す。

## 7. 意図した反復と固定形式

4コマ、定点観測、同じ構図の前後比較、反復ギャグ、ユーザーが明示した固定フォーマットなどは許可する。対象ページ、反復する要素、変える要素、読者に伝える効果を記録する。「統一感のため」「参照と同じだから」だけでは紙面全体や演技を複製する理由にならない。

場面に意味のある静けさや同じ感情の持続まで禁止しない。目的は無作為なコマ割りではなく、読みやすい物語と必要な変化である。

## 8. 導入と検証の範囲

新規プロジェクトには、既存の作成スクリプトが `skills/` と `templates/manga-project/` から本Skillと雛形をコピーする。既存プロジェクトのコピーや制作済み画像は、キットを更新しても自動では変わらない。既存作品では、更新済みSkillと入口規則を対象作品へ適用する必要がある。今回の修正だけで以前の漫画を再生成済みと報告しない。

テキストの自動テストは規則・参照・雛形の存在を検査するものであり、生成画像の構図や表情がよくなった証明ではない。実画像による検査を別に行い、未実施の評価を補わない。
