# 漫画のアートディレクション

このSkillは漫画プロジェクト一式に同梱する。作品ごとのビジュアル方針を決め、画像生成・作画の前に `docs/production/ART-DIRECTION.md` へ記録する。判断の詳細は `docs/knowledge/art-direction.md`、文字とルビは `docs/knowledge/ruby-policy.md` を参照する。

## 目的

- 物語に合う画風を選ぶ。
- 白黒・カラー・限定色などの色方針を最初に決める。
- 同一作品の全ページでビジュアルのDNAを固定する。
- 参照画像がある場合、被写体や固有要素ではなく画風要素だけを抽出して再利用する。
- 「現代っぽい」「昔話っぽい」などの曖昧な指定を、生成可能な具体要素へ分解する。

## 最初に確認する情報

`docs/story/BRIEF.md` とユーザー指示から、次を確認する。

- 時代設定：昔話 / 歴史 / 現代 / 近未来 / ファンタジー など
- ジャンル：恋愛 / 青春 / ギャグ / バトル / シリアス / 学習 / 児童向け など
- 想定読者：幼児 / 小学生 / 中高生 / 大人
- 出力目的：漫画本文 / ネーム確認 / SNS / 教材 / 絵本寄り など
- 色指定：白黒 / カラー / 限定色 / 未指定
- 画風指定と参照画像の有無
- 作品内で必ず残したい特徴と避けたい表現

情報が足りない場合でも、ユーザーが「任せる」としている範囲は作品内容から合理的な初期案を決める。作品の成否に大きく影響する条件だけを質問する。

## Style と Content を分離する

画風の一貫性を高めるため、画像生成指示では次を分けて管理する。

**Style Profile**：作品を通して安定させる要素。
- 線の太さ・強弱・密度
- 人物の頭身・顔・目・鼻・口の簡略度
- デフォルメと写実の比率
- トーン、ベタ、網点、彩色方法
- 色相・彩度・明度の傾向（カラー時）
- 光と影の硬さ
- 背景の描き込み密度
- 質感・筆致・インク感
- 効果線、速度線、ハイライトの強度
- ページ全体の静けさ / 勢い / ポップさ

**Content Prompt**：ページやコマごとに変わる要素。
- 誰がいるか
- どこにいるか
- 何をしているか
- 表情、姿勢、視線
- 必要な小道具
- コマ内で起きている出来事

Style Profile に特定の人物名、衣装、小道具、場所、物語固有の出来事を混ぜない。Content Prompt に毎回別の画風語を追加して、作品内で画風を揺らさない。

## 色の基本方針

ユーザー指定を最優先する。ただし、ユーザーが白黒・モノクロ・グレースケール等を明示していない場合、漫画はデフォルトで **フルカラー制作** とする。

### デフォルト

- 長編漫画：フルカラー
- 4コマ漫画：フルカラー
- 学習漫画・教材漫画：フルカラー
- SNS向け漫画：フルカラー
- 絵本寄り漫画：フルカラー
- ジャンル指定のみで色指定がない漫画：フルカラー

「漫画を作って」とだけ依頼された場合もフルカラーを標準とする。「漫画」「商業漫画風」「少年漫画風」「少女漫画風」という語が含まれていても、白黒漫画を自動選択しない。

暗い題材、ホラー、サスペンス、シリアス作品であっても「怖い・暗いから白黒」と自動判断しない。カラーのまま、低彩度、寒色、暗い背景、限定的な赤、補色対比、局所的な高コントラスト、照明色の偏りなどを使ってジャンル感を設計する。

### COLOR LOCK

色指定が未指定なら `docs/production/ART-DIRECTION.md` のStyle Lockに次を明記する。

- 色方針: フルカラー
- 主要パレット
- 肌の色
- 髪・衣装の基準色
- 背景の基準色
- 光源の色温度
- 低彩度 / 高彩度の範囲
- 白黒・モノクロ・グレースケールを避けること

画像生成時に `manga-ai-production` が毎ページ `COLOR LOCK: FULL COLOR / フルカラー漫画ページ / モノクロ・白黒・グレースケールではない` と同等の指定を入れられるだけの具体性を持たせる。

### 白黒にする条件

次のいずれかに当てはまる場合のみ、白黒・モノクロを採用してよい。

- ユーザーが白黒・モノクロ・グレースケールを明示した場合
- 商業漫画本文風、新聞漫画風など、媒体再現のため白黒であること自体に意味がある場合
- 演出上、白黒にする明確な理由があり、カラーより目的に適していると判断できる場合

ユーザー指定なしで白黒を選ぶ場合は、その理由を `docs/production/ART-DIRECTION.md` のStyle Lockへ記録する。「一般的な漫画だから」「漫画本文だから」という理由だけで白黒を選ばない。

### カラーFAIL条件

Style Lockがフルカラーなのに、生成結果が次の状態なら不合格とする。

- ページ全体が実質グレースケール
- 肌・髪・服・背景の大半が無彩色で、カラー指定が視覚的に成立していない
- スクリーントーン主体の白黒漫画表現になっている
- 1ページ目が白黒だったことを理由に、後続ページも白黒へ合わせている

白黒で出た1ページ目を「この作品の画風」として採用してはならない。Style Lockを優先して再生成する。

### 限定色・カラー扉

限定色やカラー扉などを混在させる場合は、使用ページと目的を先に固定し、作品全体の色設計がページごとに揺れないようにする。

## 時代・ジャンルに応じた画風の初期案

固定プリセットではなく出発点として使う。

### 昔話・和風
- 読みやすい明快な輪郭
- 落ち着いた人物造形
- 和風の建築・衣服・自然を丁寧に
- カラーでは和色、低彩度、紙・墨を思わせる質感も候補
- 白黒指定時はトーン過多にせず、墨・線・余白の印象も候補
- 児童向けなら怖さ・写実度を抑える

### 現代の青春・恋愛
- 軽めから中程度の線
- 表情と視線を重視
- 背景は駅、教室、住宅街など必要な場所情報を残しつつ人物を邪魔しない
- フルカラーでは肌、制服、夕景、教室光などの色温度を感情演出に使う
- 「最近の漫画風」とだけ指定せず、線、顔、彩色、背景密度、表情の強さを具体化する

### バトル・アクション
- 輪郭とシルエットを明確に
- 動作方向が読める効果線
- 見せ場だけコントラストを強くする
- カラーでは技・衝撃・背景の色差で視線誘導を作る
- ページごとに別画風へ変えず、勢いは構図・線密度・演出で出す

### ホラー・サスペンス
- カラーを維持しつつ、低彩度・寒色・濁った中間色を基調にする
- 赤は常用せず、視線誘導や異常の強調に限定して使う
- 顔の一部を影で隠す、背景の奥を読ませない、異常な余白を取るなど、色だけでなく構図でも恐怖を作る
- 安全な日常色と異常場面の色温度を意図的にずらす
- 影の境界、逆光、蛍光灯、非常灯、月光など光源を明確にし、立体感と不穏さを両立する
- 「怖くする＝血を増やす」ではなく、違和感、視線、距離感、シルエット、反復、見切れ、背景情報の欠落などを優先する

### ギャグ
- 表情の振れ幅を広くする
- 必要に応じて一時的なデフォルメを許可
- 通常時の基準顔を別に固定し、ギャグ顔で恒常的なキャラ形状を壊さない
- 色の切り替えや背景色の単純化はギャグ演出として使えるが、ページ全体を無彩色へ落とさない

### 学習漫画・児童向け
- 輪郭を明瞭に
- 背景情報を整理
- 説明対象と人物を競合させない
- 年齢に応じてルビ方針を設定する
- 学習要素の色分けは意味を持たせ、ページごとに同じ役割へ同じ色設計を使う

## 参照画像から画風を取る場合

参照画像を内容そのもののコピー元として扱わず、次の観点を抽出する。

1. 構図と視線誘導
2. 線と輪郭
3. 人物の形状・デフォルメ度
4. 光と影
5. 白黒表現または色設計
6. 背景密度
7. 質感・仕上げ
8. ページ全体の空気感

抽出したStyle Profileは、まったく別の簡単な題材でも同じ雰囲気が出るかを確認する。参照画像にしか存在しない人物・服・背景・小物がStyle Profileへ混入していたら修正する。

## 作品内で固定するもの

一度採用したら、明示的な演出意図がない限りページごとに変更しない。

- 白黒 / フルカラー / 限定色
- 基本の線質
- 頭身と顔の基準
- 目の描き方
- トーン・彩色方式
- 背景密度
- 光と影の基本傾向
- デフォルメ度
- 仕上げの質感

場面によって変えてよいのは、構図、カメラ距離、表情の強さ、演出上の明暗、効果線など。ただし基準画風から外れる場合は理由を記録する。

## 生成前のStyle Lock

複数ページ・複数枚を作る前に `docs/production/ART-DIRECTION.md` を埋める。最低限、次を固定する。

- 時代設定
- 読者層
- ジャンル
- 色方針
- 主要パレット
- 線
- 人物造形
- トーン / 彩色
- 背景密度
- 光と影
- 表情・デフォルメ
- 参照画像と採用した画風要素
- ルビ方針

色指定が未指定なら、このStyle Lockの色方針は **フルカラー** から開始する。白黒へ変更する場合は理由を残す。

1枚目を生成した後、Style Lockと実際の出力を比較する。色・線・人物造形のどれかがStyle Lockと違う場合、1枚目を基準にルールを変えるのではなく、まず1枚目を修正・再生成する。1枚目をそのまま新しい基準にする場合は、ユーザーの意図と一致していることを確認し、記録を更新してから2枚目以降へ進む。

## 画像生成Skillとの連携

`manga-ai-production` が画像を生成する前に本SkillのStyle Lockを確認する。Style Lockがない複数ページ作品では、先に本Skillで方針を決める。生成時はStyle Profileを毎ページ共通で保持し、ページ固有のContent Promptだけを変える。

キャラクター参照と画風参照は役割を分ける。キャラクター参照は顔・髪・服・体格などの同一性、画風参照は線・色・トーン・質感・背景密度などの一貫性に使う。

## 結果の記録

相談では採用案と理由を示す。制作では `docs/production/ART-DIRECTION.md` を更新し、画風を変更した場合は変更理由と適用開始ページを残す。未検証の「最近っぽい」「商業漫画っぽい」などの評価を事実として断定しない。
