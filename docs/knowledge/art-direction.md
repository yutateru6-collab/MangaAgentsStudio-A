# 漫画のアートディレクション

更新: 2026-09-14。

漫画の画風を「なんとなくの雰囲気」ではなく、再利用できる具体項目として固定するための制作知識。複数ページで人物や絵柄がぶれる問題を減らすことを目的とする。

## 基本原則

画風と内容を分けて考える。

- **Style**: 作品を通して安定させる見た目の設計
- **Content**: 各ページ・各コマで変わる人物、場所、行動、表情、出来事

同じ作品のページごとに「ポップ」「シリアス」「水彩」「劇画」など別の画風語を足していくと、シリーズ全体の統一が崩れやすい。まずStyleを固定し、その後はContentを差し替える。

## Style Profile の項目

作品ごとに最低限、次を言語化する。

1. 線
   - 細い / 中程度 / 太い
   - 均一 / 強弱あり
   - クリーン / ラフ / インク感
2. 人物造形
   - 頭身
   - 顔の丸さ
   - 目・鼻・口の簡略度
   - 写実とデフォルメの比率
3. 白黒表現または色
   - ベタ、網点、グレー、白場
   - カラーなら彩度、明度、色相の傾向
4. 光と影
   - 柔らかい / 硬い
   - 影少なめ / 中程度 / 強い
5. 背景
   - 記号的 / 標準 / 描き込み多め
   - 人物より目立たせるか抑えるか
6. 質感
   - 紙、鉛筆、インク、デジタル、筆、スクリーントーンなど
7. 演出強度
   - 静か / 標準 / ダイナミック
   - 効果線、集中線、ハイライトの量
8. 全体の空気
   - 明るい、温かい、切ない、緊張感、乾いた、幻想的など

## 色を決める

白黒を漫画の絶対条件にはしない。

### 白黒を第一候補にしやすいケース

- 日本語ページ漫画の本文
- 商業漫画的な仕上がりを狙う
- 印刷やネーム確認
- 線・トーン・余白で感情を見せたい

### カラーを第一候補にしやすいケース

- 幼児・低学年
- 絵本寄り
- SNS向けの短編
- 色そのものが情報になる教材
- 世界観の色設計が作品体験の中心

ユーザー指定がある場合は指定を優先する。

## 「現代っぽい」を具体化する

現代ものだから自動的に近年の漫画らしくなるとは限らない。次のように分解して指示する。

- 線: 細め〜中程度、整理されたデジタル線
- 顔: 過度に古典的な造形を避け、表情変化を細かく
- 目: 大きさと情報量を読者層に合わせる
- トーン: 必要箇所だけ使い、人物の顔を重くしすぎない
- 背景: 教室、駅、住宅街、スマートフォンなど現代の環境情報を自然に
- 表情: 微妙な視線や口元を含める
- コマ: 会話主体なら間を活かし、アクション主体なら方向性を強くする

「近年の商業漫画風」という言葉だけで済ませず、上記の具体項目をStyle Profileへ落とす。

## 時代・ジャンル別の考え方

### 昔話

- 和風の衣服・建築・自然の整合性を優先
- 線と余白の印象を活かせる
- 児童向けなら怖さ・複雑さを抑える
- 白黒でもカラーでも成立するため、読者と媒体で選ぶ

### 青春・恋愛

- 表情、視線、距離感、手元を重視
- 背景は人物関係を邪魔しない密度
- 線は軽め〜中程度を候補にする

### バトル

- シルエットと動作方向を明確にする
- 見せ場のコントラストを強くする
- 画風自体をページごとに変えるのではなく、構図と線密度で強弱を付ける

### ギャグ

- 通常顔とギャグ顔を分ける
- ギャグ時の一時的なデフォルメを許容
- 元のキャラ識別点は残す

### 学習漫画・児童向け

- 説明対象が一目で分かる
- 背景を整理する
- 文字・図・人物の優先順位を明確にする
- 読者年齢に合わせたルビ方針を採用する

## 参照画像から画風を抽出する

参照画像を使う場合、具体的な人物や物をStyleへ混ぜない。

抽出対象:

- 線
- 構図
- 光と影
- 白黒・色
- 人物のデフォルメ度
- 背景密度
- 質感
- 全体の空気

抽出後、参照画像とは無関係な簡単な題材でも同じ画風が成立するか確認する。成立しない場合は、人物名・衣装・小物・場所などContentの情報が混じっている可能性がある。

## Style Lock

複数ページ作品では、1ページ目より前に `docs/production/ART-DIRECTION.md` へStyle Profileを記録する。

1ページ目生成後に実出力を確認し、必要なら一度だけStyle Lockを修正する。2ページ目以降は同じStyle Lockを使う。途中変更は、演出上の理由と適用開始ページを記録する。

## キャラクター一貫性との違い

- キャラクター一貫性: 顔、髪、体格、衣装、識別点
- 画風一貫性: 線、色、トーン、質感、背景密度、デフォルメ度

両者を別々に固定する。キャラが同じでも画風が変われば別作品のように見え、画風が同じでもキャラ特徴が変われば同一人物に見えない。

## 参考にした外部Skill
