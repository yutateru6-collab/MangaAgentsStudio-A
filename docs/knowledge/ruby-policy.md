# ルビ・ふりがなの方針

更新: 2026-09-14。

漫画のルビは「すべての漢字に付ける / 付けない」の二択にせず、想定読者と語の難しさで決める。

## 基本方針

- ユーザー指定がある場合は最優先する。
- 全漢字へ機械的にルビを付けない。
- ルビは読みを助けるために使い、画面を過密にしない。
- 固有名詞、当て字、特殊な読み、一般的でない読みは優先してルビ候補にする。
- ルビを付けた場合は、最終出力寸法で潰れないか確認する。

## 読者別の初期方針

### 幼児・低学年

必要に応じて広めにルビを付ける。特に、物語理解に必要だが読めない可能性の高い漢字は優先する。

### 小学生

その学年・年齢で読みにくい漢字を中心にルビを付ける。既習漢字へ一律に付ける必要はない。

### 中学生・高校生

難読語、固有名詞、特殊な読み、作品固有語を中心にする。一般的な漢字へのルビは原則減らす。

### 大人・全年齢

難読語、特殊な読み、固有名詞、読みを意図的に指定したい語を中心にする。

## 判断順

1. ユーザーがルビ方針を指定しているか
2. 想定読者の年齢・学年
3. その語が読めないと物語理解に支障があるか
4. 固有名詞・当て字・特殊読みか
5. ルビによってフキダシが過密にならないか

## 画像生成時の注意

画像生成AIに文字を直接描かせる場合、ルビは誤字・位置ずれ・文字化けが起きやすい。可能なら確定セリフとルビを別の文字レイヤーで管理し、AI生成画像内の文字をそのまま最終稿にしない。

画像生成用プロンプトへは「全漢字にふりがな」のような強い一律指定を入れず、作品のルビ方針に従う。小学生向けであれば「読みにくい漢字と固有名詞に必要なルビ」といった範囲指定を使う。

## レビュー

`manga-readability-review` では次を確認する。

- ルビが必要な語に不足がないか
- 不要なルビで画面がうるさくなっていないか
- 本文とルビの対応が正しいか
- 縮小表示で読めるか
- フキダシ内の行間や文字サイズを壊していないか
