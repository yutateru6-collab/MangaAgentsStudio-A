# 10 漫画の自然な日本語・セリフ

更新: 2026-09-15。対象: 日本語漫画のセリフ、モノローグ、ナレーション、説明枠、学習漫画の説明文。

この文書は、ユーザーの `natural-japanese` リポジトリの「生成時に不自然さを予防する」「英語統語の直訳調を避ける」「読点・語順・リズムを整える」という考え方を、漫画の会話・内語・ナレーション向けに絞り込んだ制作基準である。仕事文書の結論先行や完全な文を、そのまま漫画会話へ持ち込まない。

## 1. 先に人物と関係を決める

セリフを書く前に、話者ごとに最低限次を決める。

- 年齢・学年・立場
- 性格ではなく、困ったときの反応傾向
- 相手との関係: 親友 / 友人 / 気になる相手 / 先生 / 先輩 / 家族 / 初対面など
- 普段の丁寧さ、直接さ、話す量
- 相手の呼び方、一人称
- 冗談を言うか、照れると黙るか、怒ると短くなるか
- その人物が普段は言わない言い回し

同じ人物でも、親友・先生・好きな相手・初対面では言葉遣いが変わる。全員を同じ「自然な高校生口調」にしない。

## 2. 会話は説明文ではない

漫画の会話では、文法的に完全な文より、その場で人が実際に口にする形を優先する。

自然になりやすい要素:

- 主語・目的語の省略
- 短い返事
- 言い直し
- 途中で止まる文
- 相手の言葉の一部だけを拾う返答
- 沈黙や視線、手の動きで返す
- その場で共有している情報を説明し直さない

避ける例:

- 友人同士が互いに知っている過去を読者のために説明する
- 高校生が急にレポートのような完全な定義文を話す
- 一人の人物が数コマ連続で教材を読み上げる
- 質問に対して、必要以上に整理された三段論法で答える

情報が必要でも、人物に全部しゃべらせず、図解・説明枠・画面表示・資料・行動へ分散する。

## 3. 日本語の語順で書き直す

意味が通っていても、英語の構造をそのまま日本語へ移した文は不自然になりやすい。違和感があるときは単語の置換ではなく、その場面から日本語をゼロから組み直す。

確認する:

- 「私は」「彼は」「彼女は」を連続させていないか
- 無生物主語 + 他動詞の直訳調になっていないか
- 「〜することができる」を必要以上に使っていないか
- 「〜することによって」を普通の「〜すると」「〜して」で言えないか
- 修飾が長く、述語まで遠くなっていないか
- 一文に説明を詰め込みすぎていないか

漫画では、絵が主語や状況を示しているなら、日本語からその情報を省いてよい。

## 4. 年齢・関係・感情で文章の完成度を変える

緊張、照れ、怒り、疲れ、焦りの最中に、人物が毎回きれいな完成文を言うとは限らない。

たとえば告白や強い感情の場面では、

- 言葉を選ぶ間
- 言い直し
- 相手の反応を見て文が変わる
- 最後まで言わない

などが自然な場合がある。

逆に、先生の説明、発表、放送、ニュース、教材内の定義など、整った日本語が自然な場面では完全な文を使ってよい。全場面を口語化しない。

## 5. キャラクターの声を入れ替えて検査する

重要なセリフを別のキャラクターへ入れ替えてみる。

- 誰が言っても成立する -> 声が汎用的すぎる可能性
- その人物だから自然 -> 声が分かれている

さらに同じ人物が、親友・先生・好きな相手・初対面へ同じ文を言うか考える。相手が変わっても一字一句同じなら、関係性が言葉へ反映されていない可能性がある。

## 6. 「うまいセリフ」を毎コマ作らない

AI生成の漫画では、すべての会話を気の利いた返し、名言、比喩、決め台詞にしようとすると不自然になる。

警戒するパターン:

- 毎コマにオチや名言がある
- 会話が左右対称で、必ずきれいに返答される
- 全員が同じテンポで鋭い返しをする
- 感情を描いた直後に、同じ感情を言葉で説明する
- 最後に作品のテーマをキャラクターが要約する

一つ強いセリフを残すために、周囲は普通の言葉や無言でよい。

## 7. AIっぽい言い回しを反射的に使わない

以下は全面禁止ではないが、頻度が高いとAI的・作為的に見えやすい。

- 「その瞬間」
- 「なぜか」
- 「妙に」
- 「不思議と」
- 「心臓が〜」の誇張比喩
- 「世界が止まった」
- 「これは恋だ」など感情の即時ラベル
- 「たぶん、僕は〜」で締める抽象的な総括
- 「……」「――」の連発
- 疑問文を自分で即座に答える内語

使う場合は、その人物・場面に本当に必要かを見る。同じ作品内で反復しない。

## 8. ナレーションは作文の結論にしない

ナレーションは、時間・場所・見えない情報・視点人物の認識を補うために使う。

避ける:

- 絵とセリフですでに分かる感情を説明する
- 「そして二人は大切なことを学んだ」のように教訓をまとめる
- 毎ページ最後を抽象的な一文で締める

物語の意味は、人物の選択、最後の行動、表情、物の扱いなどから読者が受け取れる余地を残す。

## 9. 学習漫画・教材漫画の説明を会話へ押し込まない

学習内容の正確さと、人物会話の自然さを分けて考える。

### 人物が言って自然なもの

- 疑問
- 感想
- 自分の理解を短く言い換える
- 相手へ尋ねる
- 体験と結び付ける

### 説明枠・図解・資料へ回しやすいもの

- 定義
- 数式・文法式
- 長い因果説明
- 専門用語の厳密な説明
- 出典どおりに保持すべき文章

教材として原文固定が必要な英語例文、日本語訳、定義、用語は、勝手に自然化・言い換えしない。`source-locked` として扱い、人物の自由会話と区別する。

## 10. 画像生成前に文字を確定する

画像生成AIへ、作品のセリフを考えさせない。

画像生成前に `docs/production/DIALOGUE.md` へ、ページ・コマ・話者・読む順・確定原文を記録する。画像生成プロンプトはその確定文を参照し、新しいセリフ・説明・キャッチコピーを追加しない。

画像AIが文字を直接描く場合でも、出力画像の文字を原稿とみなさない。確定原文と照合し、誤字・脱字・言い換え・不自然な追加文があれば修正対象とする。

## 11. 必須の自然日本語パス

字コンテまたは確定セリフを作った後、画像生成前に次を行う。

### 音読テスト

会話速度で頭の中または実際に読む。

- 口が引っかかる語順がないか
- 高校生が説明台本を読んでいるように聞こえないか
- 感情の強い場面なのに整いすぎていないか
- 同じ語尾が続いていないか

### 話者入れ替えテスト

主要なセリフを別の人物へ入れ替え、誰でも言えそうなら声を調整する。

### 相手入れ替えテスト

同じ人物が別の相手へ言う場合を想像し、距離感に応じて語彙・丁寧さ・直接さが変わるかを見る。

### 画像との重複テスト

絵で伝わる情報をセリフがもう一度説明していないか確認する。削って意味が通るなら削る候補にする。

### 教材分離テスト

正確な説明のためだけに人物が不自然に長く話していないか確認し、必要なら図解・説明枠へ移す。

## 12. PASS / FAIL

### PASS

- 年齢・関係・感情に合う言葉になっている
- キャラクターごとに言葉の選び方が違う
- 絵とセリフが役割分担している
- 学習内容の正確さを保ったまま、人物会話は会話として自然
- 音読しても口語として引っかからない

### FAIL

- 意味は正しいが、人がその場で言うとは思えない
- 説明のためだけにキャラクターが存在している
- 全員が同じ声で話す
- 毎回完璧な返答・名言・説明が続く
- 絵で分かる感情をセリフとナレーションで二重説明する
- 画像生成AIが勝手に作った日本語を、脚本確認なしで採用している

必要に応じて `yutateru6-collab/natural-japanese` の `natural-japanese` Skillを追加の文章検査として参照できる。ただし漫画会話では、本書の人物・関係・感情・省略の基準を優先し、業務文書向けの完全な文や結論先行を機械的に適用しない。
