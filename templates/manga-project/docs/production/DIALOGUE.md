# 確定セリフと文字配置の原文

セリフ・モノローグは縦書き。絵中の短い説明は横書き可。PSD内の文字がCLIP STUDIO PAINTで再編集できることは前提にしない。絵から分離した仮配置と、この原文を引き継ぐ。

このファイルは **画像生成前の文字ロック** として使う。ここに確定していないセリフ・モノローグ・ナレーション・説明枠を、画像生成AIに即興させない。

## Voice Card 確認

主要人物ごとに、年齢・関係・一人称・呼び方・丁寧さ・直接さ・感情でどう崩れるかを `docs/story/TEXT-STORYBOARD.md` で確認する。

### `source-locked`

教材の例文、公式訳、定義、数式、固有名詞、ユーザー指定の固定文など。自然に見せるためでも勝手に言い換えない。誤りや違和感の疑いがある場合は、原文を変えず別途指摘する。

### `authored`

キャラクターの自由会話、モノローグ、ナレーション、オリジナル説明文など。`docs/knowledge/manga/10-natural-japanese-dialogue.md` の自然日本語パスで調整する。

## 画像生成前チェック

- [ ] ページとコマの読む順が確定している
- [ ] 日本向けページ漫画は右上から右→左、上→下にたどれる
- [ ] 主要人物ごとの話し方が分かれている
- [ ] 年齢・関係・感情に合う日本語になっている
- [ ] 高校生や子どもが大人の説明台本のように話していない
- [ ] 絵で分かる感情や行動を文字が二重説明していない
- [ ] 音読して不自然な語順・長すぎる文・同じ語尾の連続を修正した
- [ ] `source-locked` の文章を一字一句勝手に変えていない
- [ ] 画像生成AIへ追加のセリフ・説明・キャッチコピーを考えさせる必要がない

制作メモの区切り記号をセリフへ混入させない。訂正時は原文と仮配置を両方更新し、読み順・話者・誤字を照合する。

画像内に文字を直接生成した場合でも、その画像の文字を原稿とみなさない。この表の確定原文と照合し、誤字・脱字・言い換え・文字化け・不自然な追加があれば修正する。
