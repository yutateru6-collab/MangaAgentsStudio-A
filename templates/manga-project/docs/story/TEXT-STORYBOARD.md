## コマ候補

| 読む番号 | 予定ページ・位置 | 変化の単位 | 最初に見せる主対象 | 距離・角度・視点 | 実際に描く行動・反応 | セリフ・内語・説明と話者 | source-locked / authored | 音・効果 | 次に読むコマ・視線の出口 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 右上 |  |  |  |  |  |  |  | 2へ |

日本向けページ漫画では、同じ段は右→左、上段→下段を基本とする。固定6コマではない。大ゴマ・縦長コマ・変形コマを使う場合も、各コマに読む番号と次の行き先を持たせ、番号を表示しなくても同じ順序で読める配置にする。

「悲しそう」だけでなく、目を伏せる、手を引くなど見える変化を書く。作者だけが知る内面を、読者へ既に伝えた情報として扱わない。

## 学習・教材情報の分離

必要な場合だけ使う。

- 原文を変えてはいけない例文・訳・定義・数式など：
- 人物が自然に話せる内容：
- 図解・説明枠・資料へ回す内容：
- 人物の会話へ入れると説明臭くなる内容：

`source-locked` の文章は自然に見せるためでも勝手に言い換えない。人物の自由会話は `authored` として自然日本語パスで調整する。

## 自然日本語パス

画像生成前に `docs/knowledge/manga/10-natural-japanese-dialogue.md` を参照して確認する。

- [ ] 年齢・関係・感情に合う言葉になっている
- [ ] 主要人物の声を入れ替えると違和感が出る程度に話し方が分かれている
- [ ] 同じ人物でも親友・先生・好きな相手・初対面で言葉遣いが変わる
- [ ] 高校生や子どもが大人の説明台本のように話していない
- [ ] 絵で分かる感情・行動を文字が二重説明していない
- [ ] 共有済みの情報を読者のためだけに復唱していない
- [ ] 毎コマに名言・気の利いた返し・オチを置いていない
- [ ] 音読して口が引っかかる語順や長すぎる説明を直した
- [ ] `source-locked` の文章を改変していない

## 画像生成前の文字ロック

完成したセリフ・モノローグ・ナレーション・説明枠を `docs/production/DIALOGUE.md` へ転記し、ページ・コマ・読む順・話者・確定原文を固定する。

画像生成AIへ、ここにない新しいセリフ・説明・キャッチコピーを即興させない。
